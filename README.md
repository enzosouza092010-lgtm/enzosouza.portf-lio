# Portfólio de Enzo Souza

## Rodar localmente (PowerShell, dentro da pasta)
```
npm install
npm run dev
```
Abra http://localhost:3000

## Verificações
```
npm run typecheck
npm run lint
npm run build
```

## Onde editar
- Projetos (título, descrição, tecnologias, status, imagem, link): `src/data/projects.ts`
- Textos, habilidades, processo e cursos: `src/data/site.ts`
- Imagens dos projetos: coloque em `public/projetos/`

Nenhum deploy é feito automaticamente.
